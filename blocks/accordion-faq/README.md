# accordion-faq

Custom **accordion** block. Purpose: A list of FAQ questions that expand to reveal their answers.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per question; cell 1 = question text, cell 2 = answer (rich text, or a single link to a /fragments/ page to load complex content such as nested blocks).

No variations.
