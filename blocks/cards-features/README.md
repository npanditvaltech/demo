# cards-features

Custom **cards** block. Purpose: A row of short feature or step cards, each with a title and a short description and no image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card; one cell holding an optional eyebrow paragraph (e.g. 'Step 1'), the title as a heading and a description paragraph; an optional image cell is supported.

## Supported variations

| Variation | Option class |
| --- | --- |
| Numbered Steps Top Rule | `numbered-steps-top-rule` |
