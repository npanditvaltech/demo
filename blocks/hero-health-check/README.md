# hero-health-check

Custom **hero** block. Purpose: Page-opening hero with headline, intro text and CTAs beside an interactive 'page health check' panel of score gauges.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = copy cell (h1 headline, intro paragraph, CTA links) and panel cell (title heading, run-button label as a bold paragraph, note paragraph); each further row is one gauge as 'Metric label | target score 0-100' (e.g. 'Performance | 100'). Omit the panel cell and metric rows for a copy-only hero.

No variations.
